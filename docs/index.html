End-to-End Tracking Pipeline

From raw webcam frames to Windows Media Session commands in under 15ms latency.

STAGE 01
Webcam Stream
OpenCV captures camera stream at 30 FPS with automated hardware index detection.
STAGE 02
MediaPipe FaceMesh
Extracts 468 facial landmarks + 10 dedicated iris landmarks (indices 468–477).
STAGE 03
Head Pose + Iris Vector
solvePnP projects 3D canonical face landmarks to compute normalized horizontal gaze vector.
STAGE 04
Sliding Smoother
20-frame circular buffer eliminates jitter, micro-saccades, and sudden eye blinks.
STAGE 05
Nearest Centroid
Classifies current gaze against calibration centroids saved during initial setup wizard.
STAGE 06
State Machine
Dwell timers ensure stable transitions before triggering Windows Media Session or media key events.

Quick Start & Local Setup

Run directly from source or compile to a standalone Windows executable.

# Clone the repository git clone https://github.com/PixieDigitalCreatives/attention-tracker.git cd attention-tracker # Create and activate virtual environment python -m venv venv .\venv\Scripts\Activate.ps1 # Install required dependencies pip install -r requirements.txt # Run the test suite pytest tests -v # Launch the desktop application python src/app.py # Optional: Build standalone Windows binary .\build.ps1
